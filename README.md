# Freight Rate Prediction - ML Assessment Solution

## Approach

This solution uses a chronological validation strategy because the labeled data runs from January through October 2025 while the final validation set covers November-December 2025. The main model is a small ensemble of CatBoost regressors trained on **rate per mile** and converted back to total freight rate after prediction.

Feature engineering includes calendar components, cyclical month/day-of-week encodings, lane (`pickup__delivery`), squared distance, and weight-distance interaction. CatBoost handles the categorical city/equipment/lane variables and numerical missing values directly.

## Reproduce

```bash
python -m pip install -r requirements.txt
python train_model.py \
  --train data/train-test.csv \
  --validation data/validation.csv \
  --output validation_predictions.csv \
  --december-output data/december_chart_inputs.csv

python score.py \
  --predictions validation_predictions.csv \
  --december-predictions data/december_chart_inputs.csv
```

## Validation

The principal validation split trains on Jan-Aug 2025 and evaluates on Sep-Oct 2025, simulating prediction on future months. The tuned ensemble achieved approximately:

- RMSE: 631.83
- MAE: 105.64
- Median absolute error: 33.37
- R2: 0.8286

The development data also contains a very small set of extreme rate-per-mile observations; they dominate RMSE but are not reliably inferable from the available features. Training on rate per mile improved typical error and stabilized predictions across different route distances.

## Outputs

- `validation_predictions.csv` - exactly `load_id,predicted_rate` for all 12,000 validation loads.
- `december_chart_inputs.csv` - fixed December scorer input with predictions.
- `scorer_results/candidate_december.png` - generated by the provided `score.py`.
- `freight_rate_model_report.pdf` - short submission-ready report.
